# QuotaManager · OpenWrt 25.12.6

نظام خفيف ومُعاد بناؤه من الصفر لإدارة حصص الإنترنت، تحديد السرعات، وحظر الأجهزة الغريبة والمواقع، **مخصّص للعمل حصرياً على إصدار OpenWrt 25.12.6 فقط** (بدون دعم لأي أنظمة أو إصدارات أخرى)، وبدون الحاجة إلى Python أو FastAPI أو SQLite.

يتكون المشروع من جزأين متكاملين:
1. **محرك OpenWrt أصلي (Native Bundle):** مبني بلغة `ucode` المدمجة في OpenWrt مع `nftables (fw4)` و`tc (fq_codel)` و`dnsmasq` و`uhttpd` ببصمة إجمالية تقل عن **100 KB**.
2. **لوحة محاكاة وتوليد حزمة التثبيت (Web App):** واجهة React + TypeScript + Tailwind CSS تفاعلية باللغة العربية لتجربة الحصص والرسوم البيانية وتوليد سكربت التثبيت `install_openwrt.sh` بضغطة واحدة.

## المميزات الرئيسية

### على راوتر OpenWrt الفعلي
- **خفة فائقة وحماية الـ Flash:** تشغيل كامل عبر `ucode`، وحفظ الحالة المؤقتة في الذاكرة `/tmp/quotamgr/state.json` مع المزامنة إلى `/etc/quotamgr/state.json` دورياً أو عند إيقاف الخدمة.
- **تنفيذ دفعي لقواعد الجدار الناري:** استخدام `nft -f -` بدفعة واحدة وتحديث مجموعات الحظر `@blocked_ips` و`@blocked_macs` عند التغيير فقط.
- **إدارة الحصص والقطع اللحظي:** دعم الحصة الثابتة (`Fixed`) والتقسيم المتساوي (`Equal Split`) لباقي الباقة + السقف اليومي (`Daily Cap`) + حظر الأجهزة الجديدة تلقائياً (`0 GB`).
- **تحديد السرعة وتخفيض الـ Ping:** ضبط سقف التحميل والرفع (`tc htb` + `ifb0` + `fq_codel`) لكل متصل أو مستخدم.
- **قسم DNS متكامل (`dnsmasq`):** اختيار خوادم DNS (Cloudflare Family، AdGuard، Quad9، مخصص)، إجبار DNS على المنفذ 53، التحكم بحجم الـ Cache، وحظر الإعلانات والنطاقات وسجلات الشبكة المحلية.
- **سجلات النشاط (آخر 50 عملية):** تسجيل أوقات اتصال وفصل الأجهزة وحظرها لاكتشاف الأجهزة الغريبة.
- **واجهة ويب مدمجة مستقلة:** تعمل عبر `uhttpd` على منفذ مخصص (مثل `8088` أو `8090`) مع بقاء LuCI على المنفذ `80`.

### في لوحة الويب والمحاكاة
- **لوحة الراوتر:** بطاقات ملخص الباقة، رسم بياني حي لإجمالي سرعة التحميل والرفع للراوتر بالكامل (Aggregate Traffic)، تحكم حي بالأجهزة المتصلة، وتعديل حد السرعة الفوري.
- **رسوم بيانية تفاعلية (Recharts):** عرض الاستهلاك الشهري ونسبة كل مستخدم من الباقة مع التحول للون الأحمر عند الوصول إلى **90%+** من الحصة.
- **تنبيهات ذكية داخل اللوحة:** إشعار فوري عند اقتراب أي مستخدم من 90% أو نفاد باقته اليومية/الشهرية.
- **قسم DNS:** إدارة كاملة لـ `dnsmasq` مع معاينة فورية لملف الإعدادات.
- **جدول إحصائيات آخر 7 أيام:** ملخص يومي لاستهلاك كل مستخدم.
- **سجلات النشاط (Logs):** متابعة آخر 50 اتصال/انفصال وتمييز الأجهزة غير المعيّنة مع حظر فوري.
- **الوضع الليلي (Dark Mode):** متاح في لوحة المحاكاة وفي واجهة OpenWrt المدمجة.

## التثبيت على OpenWrt 25.12.6

1. افتح لوحة الويب وانتقل إلى تبويب **«توليد الحزمة»** لاختيار:
   - الإصدار المستهدف: **OpenWrt 25.12.6** (`apk`).
   - وضع التشغيل (`router` لوضع الراوتر/البوابة، أو `ap` لوضع OpenWrt Bridge AP).
   - سعة الباقة الشهرية، يوم التجديد، المنفذ، وكلمة المرور.
2. اضغط **«تنزيل سكربت التثبيت»** للحصول على ملف `install_openwrt.sh`.
3. *(اختياري)* إذا كانت لديك بقايا من النسخة القديمة الثقيلة، أزلها عبر SSH:
   ```sh
   /etc/init.d/quota-gateway stop 2>/dev/null; /etc/init.d/quota-gateway disable 2>/dev/null; rm -rf /opt/quota*
   ```
4. ارفع السكربت إلى راوتر OpenWrt 25.12.6 وشغّله عبر SSH (مع استبدال `192.168.1.1` بعنوان الراوتر):
   ```sh
   scp -O install_openwrt.sh root@192.168.1.1:/tmp/
   ssh root@192.168.1.1 "chmod +x /tmp/install_openwrt.sh && sh /tmp/install_openwrt.sh"
   ```
   > يتحقق السكربت تلقائياً من `/etc/openwrt_release` بأن الإصدار يساوي **`25.12.6`** مع توفر `apk` و`ucode` و`fw4`، ولن يُثبت على أي إصدار آخر.
5. افتح لوحة التحكم من المتصفح عبر:
   ```text
   http://192.168.1.1:8088
   ```
   *(أو المنفذ الذي اخترته أثناء التوليد — بيانات حساب الأدمن الافتراضي: اسم المستخدم **`مصطفي`** وكلمة المرور **`0`**، ويمكن تعديلهما أو إلغاء القفل من الإعدادات).*

للتحقق من الخدمة والذاكرة في أي وقت:
```sh
logread -e quotamgr && free -m && df -h /overlay
```

## تشغيل لوحة المحاكاة محلياً (للتطوير)

npm run lint

npm run build
